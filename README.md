
# Cloud & DevOps Engineering Portfolio

## About This Portfolio

This portfolio documents my hands-on experience with AWS, Terraform, Docker, Kubernetes, infrastructure automation, and troubleshooting.

Each project demonstrates practical skills in deploying, managing, testing, and recovering cloud infrastructure and applications.

---

## Project 1: Cloud Website Deployment

**Technologies:** AWS, Terraform, EC2, Nginx, Git, GitHub

**What I built:** Provisioned AWS infrastructure using Terraform and deployed a working Nginx website on an EC2 instance.

**Skills demonstrated:** Infrastructure as Code, cloud networking, web server deployment, and infrastructure validation.

**GitHub:** https://github.com/jwatson2026/cloud-website-project

---

## Project 2: Kubernetes Website Reliability Incident

**Technologies:** Kubernetes, Docker Desktop, kubectl, YAML, GitHub

**What I built:** Deployed an Nginx website and simulated an application connectivity incident by introducing a mismatch between a Kubernetes Service selector and Pod labels.

**Skills demonstrated:** Incident troubleshooting, Kubernetes networking, service discovery, root cause analysis, and recovery verification.

**GitHub:** https://github.com/jwatson2026/website-reliability

---

## Project 3: AWS EKS Application Deployment

**Technologies:** AWS EKS, EC2, Kubernetes, Nginx, AWS CLI, kubectl

**What I built:** Created an AWS EKS environment, deployed Nginx, exposed the application using a LoadBalancer Service, and tested Pod scaling and automatic replacement.

**Skills demonstrated:** Managed Kubernetes, application deployment, scalability, self-healing, and cloud resource cleanup.

**GitHub:** https://github.com/jwatson2026/aws-eks-nginx-lab

---

## Project 4: Kubernetes Stateful Workload Recovery

**Technologies:** Kubernetes, Docker Desktop, Persistent Volumes, Persistent Volume Claims, YAML, kubectl

**What I built:** Deployed an application with persistent storage, intentionally deleted its Pod, and verified that Kubernetes automatically replaced it while preserving application data.

**Skills demonstrated:** Persistent storage, application recovery, Kubernetes Deployments, troubleshooting, and infrastructure validation.

**GitHub:** https://github.com/jwatson2026/k8s-stateful-workload-recovery
